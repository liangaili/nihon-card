本来读さけ的酒，在“居酒屋”里为什么读成了ざか？

发表于 2018-10-11 · 原文：点击查看

酒字本来训读为さけ，到了居酒屋(いざかや)里，读音却变成了ざか。


从さけ变成ざか，发生了两个变化，一个是さ变成ざ，一个是け变成か。


先说け变成か，如果有留意的话，会发现日语中这样的现象还不少：


・（雨）あめ＋かさ　→　（雨傘）あまがさ

・（稲）いね＋ほ　　→　（稲穂）いなほ

・（上）うえ＋はき　→　（上履き）うわばき

・（風）かぜ＋かみ　→　（風上）かざかみ

・（金）かね＋もの　→　（金物）かなもの

・（声）こえ＋いろ　→　（声色）こわいろ

・（酒）さけ＋くら　→　（酒蔵）さかぐら

・（手）て　＋おる　→　（手折る）たおる

・（爪）つめ＋ようじ→　（爪楊枝）つまようじ

・（苗）なえ＋しろ　→　（苗代）なわしろ

・（舟）ふね＋もり　→　（船盛）ふなもり

・（船）ふね＋やど　→　（船宿）ふなやど

・（胸）むね＋いた　→　（胸板）むないた

・（棟）むね＋き　　→　（棟木）むなぎ

(注意日语中同音训读字往往意义接近：舟-船，胸-棟)


上面这些例子的共同特点是，发音的尾音都是え段假名，组合成词的时候，有时会变为あ段假名。


其中特殊的是(苗)なえ，转音后变成了なわ，这可能是之前我们在一篇消失的假名中所提到过的，在历史中，假名ゑ(we)消失之后变成了え。在我们学ない形的时候，像言います、買います变成了言わない、買わない，可能也是消失的假名ゐ(wi)所导致。


像这种え段假名变成あ段假名的现象叫做“母音交替”。


学英语的小伙伴们可能也注意过英文中有些特殊的变化：


foot -> feet

mouse -> mice

song -> sang -> sung


这些，其实也都是母音交替现象。


除了え段→あ段以外，其他段的变化也有：


い段→お段

・（木）き＋かげ→　（木陰）こかげ

・（火）ひ＋かげ→　（火影）ほかげ


い段→え段

・（気）き＋はい→　（気配）けはい


お段→あ段

・（白）しろ＋こ→　（白子）しらこ


这里需要注意一点，并不是在这些字后面加其他的词构成复合词就一定会发生母音交替，金持ち还是要读作かねもち的。


那么，应该什么时候用母音交替，什么时候不用母音交替呢？


以雨为例，它读作あめ，发生母音交替的时候，读作あま。


读作あめ的场合，多是雨的本意，或是雨与其他词并列：

「雨風」「雨上がり」「雨降り」


读作あま的场合，多是用来修饰其他的词：

「雨蛙」：一种小型青蛙。

「雨傘」：防雨的伞。

「雨雲」：会导致下雨的云。


而当雨風读作あめかぜ的时候，是“雨和风”的含义、而读成あまかぜ的时候，则是夹着雨的风的感觉。


参加这种跨段“母音交替”的，多是名词，而读音的跨段变化，并不是名词身上才有，大家更熟悉(痛恨)的，应该就是动词的变形了吧：


好端端的一个聞く，后面的く字，在各种变形之下，把かきくけこ五段假名都用上了(这也正是“五段动词”中“五段”之所指)，比起前面提到的少数名词的“母音交替”，词语虽然更多，但是变化也更规律了。


以前总能看到“同一行的假名意思(有时)就是一样的”这样的说法，现在总算开始有点摸到门道了的感觉。


至于さ变成ざ，是“连浊”，是“字音交替”的一种，这个就先不说了，以后什么时候再补。
